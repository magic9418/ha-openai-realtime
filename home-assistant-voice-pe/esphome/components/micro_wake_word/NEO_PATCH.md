# micro_wake_word held-duck patch

Local vendored copy (see git log for the diag/sat1 vendoring). One addition on top of it:
`MicroWakeWord::get_last_detection_average()` / `get_last_detection_max()` (uint8, 0-255 on the cutoff
scale), set from the `DetectionEvent` immediately before `wake_word_detected_trigger_.trigger()`.

Used by `config/common/neo_voice.yaml` (`on_wake_word_detected`) -> `va_ws.capture_wake_trigger(...)`
-> `wake_trigger_start.detector_score` / `detector_score_max`. No behaviour change to detection:
three assignments + two getters + two members. `average` is the sliding-window mean already computed
by `WakeWordModel::determine_detected()` (integer sum / window, so 1/255 resolution).

# Stage 2 + feature history (2026-11-10, branch feat/wake-stage2)

A second, tiny int8 model (`penny_stage2_v1`, 22 KB, 5 ops) scores the 100 feature frames ending at the
stage-1 firing frame, once per detection, on the inference task. New files: `wake_features.h` (feature history
ring + result types, host-testable), `wake_stage2.{h,cpp}` (runner, self-test, prefs, counters),
`wake_stage2_selftest.h` / `wake_stage2_expected.h` (self-test inputs generated by code; expected outputs from
`tools/gen_stage2_selftest.py`). Hooks in `micro_wake_word.{h,cpp}` / `streaming_model.{h,cpp}`: record each
feature frame + held stage-1/VAD probabilities, evaluate stage 2 at the firing invocation (inside the
`vad_state.detected` branch, before the detection is queued), `on_wake_word_rejected` trigger, runtime setters.
Inference task stack 3072 -> 4096 (stage 2 skips itself if < 1536 B headroom).

Memory added (all PSRAM, allocated once in setup()): feature history 10,500 B, stage-2 arena 131,072 B default (YAML
`tensor_arena_size`). Fail-open: any failure => status != ok, mode reports "off", behaviour identical to before.
Modes: off | shadow (score+report, always pass) | enforce (score < threshold rejects, cold-idle regime only; else shadow).
Control: `set_stage2_mode/threshold/cold_idle`, persisted via ESPHome preferences (main loop), threshold 0 = default.
The two copies of this component carry byte-identical additions (new files identical; hooks applied by the same patch).

Self-test (v3): expected outputs are the TFLM reference values (-39,-95,-69); tolerance +-12 per vector, plus "not all three identical".
ESP-NN's optimised kernels on the ESP32-S3 differ from the reference by a few LSB on these extreme synthetic inputs (measured
on the Voice PE: got -32,-92,-69, dev 7), so the test only catches gross failure. Real-data parity is checked offline from the
uploaded features (device score vs offline score on the same features). Log: `selftest=PASS got a,b,c dev=N`.
